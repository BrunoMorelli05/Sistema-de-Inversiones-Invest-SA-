# Invest S.A -Sistema de Gestión de Inversiones

#Descripción
Sistema de administración de inversores y acciones bursátiles desarrollado en C# con Windows Forms.

#Funcionalidades
Alta, baja y modificación de inversores y acciones
Compra y venta de acciones con cálculo automático de comisiones
Dos tipos de inversores: Común y Premium con diferentes esquemas de comisiones
Actualización automática de valores por eventos de cotización
Ordenamiento por columnas en las grillas

#Tecnologías
C# .NET
Windows Forms
Programación Orientada a Objetos

#Conceptos aplicados
Herencia y polimorfismo
Interfaces (IComparer, IEnumerable, ICloneable, IDisposable)
Eventos personalizados
Excepciones personalizadas
Binding con BindingList y clases de vista
